Le logotype complet, format portrait : cocotte, filets, « CHAUD / DEVANT », millésime. La couleur vient de `currentColor` — pose `text-rouge` (fond clair) ou `text-creme` (fond sombre) sur le composant, et donne-lui une largeur (`w-52`, `w-64`…). `mention="restaurants"` sort la version « RESTAURANTS SINCE 2026 » pour les supports où la marque se présente comme maison de restauration ; le site reste sur `since`.
