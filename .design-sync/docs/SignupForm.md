Le formulaire d'inscription : un champ mail souligné (pas de boîte grise — on vend une cocotte, pas un logiciel), une case décochée pour les nouvelles, le bouton plein « Je prends ». Sans props. Après envoi, il cède la place au message de confirmation au même endroit, avec les liens sociaux. Dans l'environnement design, la soumission montre cet état « envoyé » ; dans l'app, l'action serveur écrit en base et déclenche le double opt-in.
